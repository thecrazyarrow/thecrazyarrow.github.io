Put your 3D files here (.stl, .3mf, .obj, .glb, .gltf).
Then point a viewer at it in manufacturing.html (or projects.html):
    data-model="models/your-file.stl"
A space in a file name is written as %20 in the path, e.g. models/GUITAR%20BODY.stl
(dashes instead of spaces are easier: my-part.stl).
Keep files under ~20 MB so the page loads fast. Export STL as binary, not ASCII.
